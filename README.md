# LionO access URL

This repository serves `https://liono.kawaitechnologies.com` through GitHub
Pages and redirects visitors to the live LionO Sight application.

The repository intentionally contains no LionO application source, credentials,
company data, database files, or OAuth secrets.

## Live destination

`https://lucem-mac-mini-server.tailbd9f6c.ts.net:8443/`

The redirect preserves the requested path, query string, and URL fragment.
The doorway also mirrors LionO's tab title, favicons and Open Graph/Twitter
preview metadata so shared WhatsApp links identify the same application.
